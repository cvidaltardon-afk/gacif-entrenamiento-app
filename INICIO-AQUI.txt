🆘 SI ALGO FALLA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "npm: command not found"
   → Instala Node.js desde https://nodejs.org

❌ "Port 3000 in use"
   → npm run dev -- --port 3001

❌ "Can't find module"
   → npm install

❌ "Blank page"
   → F12 → Console, busca errores rojos

❌ "Datos no se guardan"
   → F12 → Application → Storage → localStorage

Para más ayuda: Lee README.md o abre Issue en GitHub
